# 麦轮小车项目 — 整体介绍与客户端接入指南

> **项目代号**：V1 · STM32F407 Mecanum 四轮麦轮导航小车
> **本文用途**：给开发**客户端 App / 微信小程序 / Web 控制端**的同事阅读 —— 讲清系统是什么、有哪些接口、怎么接入。
> **配套文档**：`Core/docs/communication-protocol.md`（完整串口协议）

---

## 1. 项目一句话

一辆 **STM32F407 驱动的四轮麦轮（Mecanum）小车**，板载 9 轴 IMU（MPU9250）、四路编码器、TB6612 电机驱动，可任意方向平移、原地旋转、速度闭环；上位机由 **RK3588（Linux + ROS2）** 承担，负责串口桥接、激光雷达 SLAM 建图、自主导航、摄像头、Web/远程控制。

```
┌────────────────────────────────────────────────────────────────────┐
│                        客户端 App / 微信小程序                         │
│               (WiFi / 局域网 HTTP+JSON 或 WebSocket)                  │
└───────────────────────────┬────────────────────────────────────────┘
                            │  HTTP: http://<RK3588_IP>:8765/send?cmd=...
                            │  HTTP: http://<RK3588_IP>:8765/data (遥测)
┌───────────────────────────▼────────────────────────────────────────┐
│                 RK3588 上位机 (Ubuntu 24.04 + ROS2 Jazzy)             │
│   ┌──────────────┐ ┌──────────────┐ ┌────────────┐ ┌──────────────┐  │
│   │ serial_bridge │ │ slam_toolbox │ │  nav2      │ │ camera_bringup│  │
│   │ 串口桥+Web    │ │ 激光SLAM建图  │ │ 自主导航    │ │ USB摄像头    │  │

└─────────────────────────────────────────────────────────────────────┘
```

## 2. 硬件组成

| 模块 | 型号/规格 | 说明 |
|------|-----------|------|
| 主控 | STM32F407ZGT6 @168MHz | 下位机，裸机裸跑（无 RTOS） |
| 电机 | MC520P30_12V × 4（13PPR 编码器，30:1 减速，输出轴 52 计数/转） | 带霍尔/AB 编码器 |
| 电机驱动 | TB6612 × 2 | 每片两路 H 桥，10kHz PWM |
| IMU | MPU9250（9 轴：加速度计+陀螺仪+磁力计） | I2C1 100kHz，含总线故障自恢复 |
| 上位机 | RK3588 开发板（Ubuntu 24.04） | 串口桥、SLAM、导航、摄像头、Web |
| 激光雷达 | RPLIDAR A1/C1 系列 | SLAM 建图 / 激光里程计 |
| 摄像头 | DH-200W-X1 USB 相机 | 路标识别 / 车道保持（预留） |
| 通信 | USART2 (PD5=TX, PD6=RX)，**460800 8N1** | 下位机 ↔ 上位机 |
| 供电 | 12V 电池组 | 电机驱动 + 主控 |

## 3. 软件组成

### 3.1 下位机固件（C，STM32CubeMX + CMake + arm-none-eabi-gcc）

| 模块 | 文件 | 职责 |
|------|------|------|
| 串口驱动 | `uart_io.c/.h` | TX 环形缓冲+DMA 异步发送，RX 中断环形缓冲，printf 重定向 |
| 调试日志 | `debug.c/.h` | 5 级日志（NONE~VERBOSE），带时间戳+模块名 |
| IMU 驱动 | `mpu9250.c/.h` | 9 轴采集、陀螺/磁力计校准、I2C 故障自恢复 |
| 航向融合 | `ahrs.c/.h` | 互补滤波（陀螺+磁力计），ZARU 零速零偏再估计 |
| 里程计 | `odometry.c/.h` | 麦轮正运动学 + EKF 融合 + 航位推算 + 诊断 |
| 底盘 | `chassis.c/.h` | 麦轮逆运动学 + 状态机（IDLE/TURNING/MOVING/MANUAL/DONE） |
| 电机 | `motor.c/.h` | 编码器测速 + 增量式 PID 速度闭环 + PWM |
| 遥测 | `telemetry.c/.h` | ASCII `$T` / 二进制帧打包，50Hz |
| OTA | `ota.c/.h` | 版本查询 + 升级标记 → 软复位进 Bootloader |
| 命令入口 | `main.c` | 串口命令解析分发、主循环 |

### 3.2 上位机（ROS2 Jazzy，Python）

| 包 | 节点 | 职责 |
|----|------|------|
| `mecanum_bringup` | `serial_bridge` | **串口桥**：解析 407 遥测 → ROS2 话题（/odom、/imu 等）；订阅 /cmd_vel → `V` 命令 |
| `mecanum_bringup` | `keyboard_teleop` | 键盘遥控（按住动、松开停） |
| `odom_compare_web` | `odom_compare_bridge` | **Web 控制 + 里程计对比**，HTTP 端口 **8765**（也是小程序首选后端） |
| `camera_bringup` | `mjpeg_camera_node` | USB 摄像头 MJPG 采集发布 |
| `mecanum_bringup_hector` | — | 激光 SLAM + 导航 launch 集合（slam_toolbox / nav2） |
| — | `rplidar_ros` | 激光雷达驱动 |
| — | `rf2o_laser_odometry` | 激光里程计（与轮式里程计对比） |

### 3.3 ROS2 关键话题（供参考，客户端一般不直接用）

| 话题 | 类型 | 内容 |
|------|------|------|
| `/odom` | nav_msgs/Odometry | 407 融合位姿+速度（带 EKF 协方差） |
| `/odom_laser` | nav_msgs/Odometry | 激光里程计 |
| `/cmd_vel` | geometry_msgs/Twist | 速度指令（桥转成 `V` 命令） |
| `/imu/imu407/data_raw` | sensor_msgs/Imu | 原始 IMU 转 SI |
| `/imu/imu407/mag` | sensor_msgs/MagneticField | 磁力计 |
| `/wheel_encoders` / `/wheel_speeds` | 数组 | 编码器/轮速 |
| `/stm32_tick` | std_msgs/Int32 | 407 tick 对齐 |
| `/chassis_status` | std_msgs/String | `$STAT` 原始行 |
| `/odom_diag` | std_msgs/String | ODOM EKF 诊断 JSON |
| `/image_raw/compressed` | sensor_msgs/CompressedImage | 摄像头压缩图 |

## 4. 给客户端开发者的接入指南

> 客户端（App / 小程序 / Web）**不需要也不应该直接碰串口**。所有控制与遥测统一走 **RK3588 上的 HTTP 服务**（或将来扩展的 WebSocket）。

### 4.1 后端服务（首选：odom_compare_web，端口 8765）

在 RK3588 上启动：

```bash
ros2 launch odom_compare_web odom_compare.launch.py
```

启动后暴露以下 HTTP 接口：

| 接口 | 方法 | 说明 |
|------|------|------|
| `GET /` | GET | 内置 Web 控制面板（人肉调试用） |
| `GET /send?cmd=<URL编码命令>` | GET | **发送任意串口命令**，返回 `{"ok":true}` |
| `GET /data` | GET | **遥测 JSON 快照**（见 4.3） |
| `POST /baseline` | POST | 设置对比基准点 |
| `POST /clear` | POST | 清空轨迹历史 |

**命令速查（完整协议见 communication-protocol.md）：**

| 场景 | 命令 |
|------|------|
| 前进/后退/横移/旋转 | `V,<vx>,<vy>,<wz>`（vx∈[-1,1]m/s, vy∈[-1,1]m/s, wz∈[-3,3]rad/s） |
| 急停 | `STOP` |
| 开启遥测（ASCII） | `TELEM,ON` |
| 开启遥测（二进制） | `TELEM,BIN` |
| 关闭遥测 | `TELEM,OFF` |
| 里程计归零 | `ODORST` |
| 设置位姿 | `ODOSET,<x>,<y>,<hdg>` |
| 查询状态 | `STATUS` |
| 查询版本 | `VERSION` |
| 单轮测试 | `W1,60` / `WALL,60` / `WALL,STOP` |

**客户端最小接入流程：**

```
1. 设置后端地址: http://<RK3588_IP>:8765
2. 连接测试:     GET /data 能返回 JSON 即连通
3. 开启遥测:     GET /send?cmd=TELEM%2CON
4. 控制:         GET /send?cmd=V%2C0.3%2C0%2C0   (发送 V,0.3,0,0)
5. 遥测轮询:     GET /data 每 500ms 取一次位姿/航向/轮速
6. 安全:         任何异常/断线/用户松手 → GET /send?cmd=STOP
```

### 4.2 备选接入方式

| 方式 | 说明 | 适用 |
|------|------|------|
| **HTTP (8765)** | 现成可用，JSON 明文，最省事 | ✅ 推荐，小程序/App 首选 |
| **串口直连** | 需 USB-TTL/蓝牙/WiFi 串口透传接 460800 8N1，自行解析协议 | 无 RK3588 时 |
| **WebSocket** | 后端暂未内置；可自行在 RK3588 加一个 WS 网关转发命令+推送遥测 | 需要服务器推送时 |

> 注意：微信小程序 `wx.request` 正式版只允许 HTTPS 域名。**开发调试**时在开发者工具勾选"不校验合法域名"即可用 `http://<IP>:8765`；**正式发布**需为后端配置 HTTPS 域名（或改用 WSS）。同一局域网下手机直连 RK3588 IP 即可。

### 4.3 `/data` 遥测 JSON 结构

```json
{
  "wheel": [ {"x":0.12,"y":0.03,"yaw":0.015,"vx":0.3,"vy":0.0,"wz":0.0,"stamp":1234.5}, ... ],
  "laser": [ ... ],
  "latest": {
    "wheel": {"x":0.12,"y":0.03,"yaw":0.015,"vx":0.3,"vy":0.0,"wz":0.0,"stamp":1234.5},
    "laser": null
  },
  "mag": {"x":30.2,"y":-8.7,"z":45.1},
  "diag": {"flags":1,"q_xy":0.001,"q_yaw":0.002,"r_heading":0.01,"cov_x":1e-5,"cov_y":1e-5,"cov_yaw":1e-4},
  "baseline": null
}
```

客户端最常用的字段是 `latest.wheel`（x/y 米、yaw 弧度、vx/vy/wz）和 `diag`（EKF 诊断）。

### 4.4 坐标系与单位（务必与车一致）

```
- 机器人系: X=前, Y=左, 旋转逆时针为正
- 世界系:   X=北(开机方向), Y=西, heading 罗盘角 0°=北顺时针增
- /data 的 yaw 为弧度(ROS 约定, 0=北, 逆时针正 = -罗盘角)
- V 命令:   V,<前/后m/s>,<左/右m/s>,<旋转rad/s>
```

### 4.5 安全须知（写进你的客户端）

1. **急停按钮必须常驻、显眼**（发 `STOP`）。
2. 速度指令设置**软限幅**：线速度 ≤ 0.5 m/s（调试期），角速度 ≤ 1.5 rad/s。
3. 遥控操作**松手即停**：触摸结束时立即发 `STOP`。
4. 网络断线/轮询超时 > 2s：提示"连接断开"并自动发一次 `STOP`（保守策略）。
5. 首次使用先 `STATUS` 确认状态，再小速度试动。

## 6. 常见部署步骤（RK3588 上位机）

```bash
# 1. 串口权限
echo 'KERNEL=="ttyS1", MODE="0666"' | sudo tee /etc/udev/rules.d/99-ttyS1.rules
sudo udevadm control --reload && sudo udevadm trigger

# 2. 编译 ROS2 包
cd ~/ros2_ws && colcon build --packages-select mecanum_bringup odom_compare_web

# 3. 启动 Web 控制服务（含串口桥）
ros2 launch odom_compare_web odom_compare.launch.py

# 4. 浏览器验证
#    电脑/手机同一局域网访问 http://<RK3588_IP>:8765/
#    防火墙: sudo ufw allow 8765/tcp
```
