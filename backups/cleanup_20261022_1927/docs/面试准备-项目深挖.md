## 3. 项目高频深挖问题

### 3.1 为什么不用轮式里程计？

回答模板：

```text
因为这是麦轮底盘。
麦轮在横移和打滑时，编码器里程计误差会明显变大，
导致建图时地图重影/撕裂。

所以我改用 rf2o 激光里程计，
它直接利用连续两帧激光雷达做匹配，
不和轮子打滑耦合，
在结构化环境里更稳定。
```

### 3.2 激光里程计和轮式里程计数据有什么不同？

```text
两者 ROS 数据类型都是 nav_msgs/Odometry。
区别在数据来源：
轮式 = 编码器积分 + AHRS 航向投影；
激光 = 连续激光帧匹配。
```

### 3.3 你是怎么排查轮式/激光里程计方向不一致的？

回答模板：

```text
我用 Web 工具同时显示两条轨迹。
只按 W 前进 1 米，
发现激光里程计 X 增加，
轮式里程计 X 反而减少，
两者方向接近 180 度相反。

后来发现是激光雷达扫描坐标系相对车头反了 180 度，
我修改了 base_link -> laser 静态 TF 的 yaw，
从 0 改成 pi。
```

### 3.4 麦轮运动学公式能不能写？

```c
w[0] = ( vx - vy - omega * L) / R;  // FL
w[1] = ( vx + vy + omega * L) / R;  // FR
w[2] = ( vx + vy - omega * L) / R;  // RL
w[3] = ( vx - vy + omega * L) / R;  // RR
```

要能解释：

```text
vx = 前后速度
vy = 左右速度
omega = 旋转角速度
L = Lx + Ly
R = 轮半径
```

### 3.5 Nav2 Jazzy 你踩过哪些坑？

```text
1. nav2_recoveries 改名 nav2_behaviors，
   可执行文件是 behavior_server。
2. 插件名用双冒号，
   例如 nav2_navfn_planner::NavfnPlanner。
3. costmap width/height 必须是整数，不能写 3.0。
4. map_server 不会主动发布 /map，
   需要调用 /map_server/map 服务。
5. Nav2 生命周期节点需要 configure + activate。
```

### 3.6 map_server 不主动发布地图怎么解决？

```text
调用 /map_server/map 服务拿回地图。
我又写了一个 map_trigger 节点，
把地图缓存下来并以 1Hz 持续发布 /map，
解决后续订阅者收不到地图的问题。
```

### 3.7 磁力计问题？

回答模板：

```text
磁力计开启后航向会被固定在一个角度。
我通过串口遥测发现磁力计原始值异常：
X/Y/Z 基本固定，旋转小车也不变。
判断是 AK8963 没有进入正确的连续测量模式，
或者标定/轴映射有问题。

当前导航和里程计测试阶段，
我保持 AHRSMAG OFF，
只使用陀螺仪积分 + 激光里程计兜底。
```

### 3.8 串口协议怎么设计的？

```text
STM32 与 RK3588 使用 460800 8N1。
命令格式是 V,0.3,0,0 这种文本命令。
遥测有两种：
ASCII $T 方便调试；
二进制 0xAA55 + CRC8 更可靠，带宽小。
```

### 3.9 为什么底盘不用 RTOS？

回答模板：

```text
底盘主循环是 10ms 裸机轮询，
任务只有串口、电机 PID、IMU、遥测，
没有强实时抢占需求。
裸机更简单，更容易调试。

如果以后要加多传感器同步、
高频率控制、复杂任务调度，
我会考虑引入 FreeRTOS。
```

### 3.10 OTA 流程？

```text
RK 发送 CMD_OTA_START，
App 写升级标记后软复位。
Bootloader 检测到标记进入升级模式，
通过 UPDATE/ADDR/DATA/RUN 协议写 App。
RUN 后清标记并跳转到 0x08010000。
```

## 4. 嵌入式八股高频题

### 4.1 C 语言

| 问题 | 关键回答 |
|---|---|
| volatile 作用 | 告诉编译器每次访问都从内存读，不要优化到寄存器 |
| static 作用 | 局部变量保持生命周期；全局变量限制文件作用域 |
| const 作用 | 只读，不能被修改 |
| 指针和数组 | 数组名是首地址常量；指针可以改变指向 |
| 结构体对齐 | 成员按最大对齐数对齐，可能产生 padding |
| 大小端 | 小端：低字节在低地址；大端相反 |
| malloc 注意 | 要 free，避免内存碎片；嵌入式尽量不用动态分配 |

### 4.2 FreeRTOS

| 问题 | 关键回答 |
|---|---|
| 任务和裸机区别 | 任务有独立栈、可被调度器切换 |
| 信号量 | 用于同步/互斥，二值/计数 |
| 互斥锁 | 防止多任务同时访问共享资源，有优先级继承 |
| 消息队列 | 任务间传递数据 |
| 优先级反转 | 低优先级任务持有锁，高优先级任务被阻塞；互斥锁/优先级继承解决 |
| 死锁 | 两个任务互相等对方资源 |

### 4.3 Linux

| 问题 | 关键回答 |
|---|---|
| 进程和线程 | 进程资源隔离，线程共享内存，线程切换更轻 |
| 设备树 | 描述硬件信息的树形数据结构，驱动从中读取资源 |
| 内核裁剪 | 按需配置内核功能，减小体积/加快启动 |
| 串口调试 | stty、cat、/dev/ttyS1 |
| systemd | 管理开机服务 |

### 4.4 ROS2

| 问题 | 关键回答 |
|---|---|
| 节点 | 一个可执行单元 |
| 话题 | 异步通信，多个订阅者 |
| 服务 | 同步请求/响应 |
| Action | 长时间任务，可反馈、可取消 |
| TF | 坐标变换树 |
| QoS | 通信质量策略，如 reliable/best_effort、volatile/transient_local |
| Lifecycle | 节点生命周期：unconfigured -> inactive -> active |
