# 秋招岗位定位与两周计划

> 背景：二本本科，STM32F407 + RK3588 + ROS2 麦轮小车项目  
> 目标：秋招嵌入式 / 机器人软件方向  
> 时间：约两周

---

```text

```


## 2. 可以投的岗位

### 第一梯队（最匹配）

| 岗位名称 | 说明 |

| 嵌入式 Linux 软件工程师 | RK3588 经验非常对口 |
| 机器人软件工程师 | ROS2 + 电机 + 雷达，正好对口 |
| ROS2 开发工程师 | 少数公司有这个岗位，看到直接投 |
| 智能硬件嵌入式工程师 | 适合消费电子/机器人公司 |

| 岗位名称 | 说明 |
|---|---|
| 单片机开发工程师 | 纯 STM32 方向 |
| 嵌入式软件工程师（应用层） | 偏 Linux 应用 |
| 机器人应用开发工程师 | 偏 ROS/算法调用 |
| 自动化设备软件工程师 | 工业设备，嵌入式为主 |

## 8. 简历项目重点

```text
- 完成 STM32F407 麦轮底盘固件
- 完成 RK3588 上位机 ROS2 通信
- 使用激光雷达 + 激光里程计建图
- 集成 Nav2 自主导航
- 开发 Web 远程监控/控制界面
- 定位并解决雷达方向反 180°、轮式/激光里程计方向不一致、磁力计航向漂移等问题
```
