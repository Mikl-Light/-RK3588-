## 二、当前遗留问题（按优先级）

### 🔴 P0：cmd_vel 与 /odom 坐标系约定差 90°（建图前必须对齐）

- 用户已把 `cmd_vel_cb` 改为"**Vx = 前**"约定（`Vx=-linear.x, Vy=+linear.y`），手动键盘正常；
- 但桥的 `publish_binary` 里 odom 输出**还是老映射**（`linear.x = vy` 即"Vy=前"）→ **odom 的速度/位姿方向和真实运动差 90°**；
- 手动开看不出来，**rviz2 建图会地图横着长、导航方向全错**；
- 待办：改 `publish_binary` 的 odom 段（`linear.x=vx, linear.y=-vy`），**符号别猜，悬空实测**：
  ```bash
  ros2 topic echo /odom
  # 按 W → linear.x 应为 +0.3；按 A → linear.y 应为 +0.3；按 Q → angular.z=+0.8 且 yaw 增大
  ```

### 🟠 P1：yaw / pose 映射未实测

- `to_ros_yaw()` 用的是文档约定（`yaw = π/2 − heading`，`invert_yaw` 参数可翻）；
- 磁力计安装方向、罗盘角 vs 实际旋转方向**均未实车验证**；
- 待办：Q 左转时看 `/odom` 的 yaw 是否增大；反了改 `pose_invert_yaw` 参数（不用改代码）；
- 方案二（待用户选）：把 odom 段改成符号参数（vx_sign/vy_sign/yaw_sign/xy_swap），参数文件里调。
