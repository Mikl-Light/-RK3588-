## 一、今日完成

### 1. 固件运动学 ROS 化（重要变更，含一次纠错）

| 项 | 内容 |
| --- | --- |
| 需求 | 按 ROS 规定：`V,<Vx>,<Vy>,<Wz>` → **Vx=前, Vy=左, Wz=逆时针正(左转)** |
| 过程 | 先做了 90° 旋转变换 → **用户实测 `V,0,0.5,0` 车后退**抓出错误 → 推导标准麦轮物理：**前进=四轮同向转、横移=对角反向、旋转=斜对角反向** → 恢复原始公式（它本来就是 x=前/y=左 的标准麦轮公式，只是旧注释标错成"X=右 Y=前"） |
| 最终公式 | `w_FL=(vx-vy-ωL)/R, w_FR=(vx+vy+ωL)/R, w_RL=(vx+vy-ωL)/R, w_RR=(vx-vy+ωL)/R` |
| 轮速模式 | 前进=`++++`，左移=`-++-`，左转=`-+-+` |
| 世界系 | X=北, Y=西（右手系），ROS yaw = -罗盘角 |
| 验证 | 1000 组随机速度逆/正运动学互逆 PASS；**实机未烧录验证** ⚠️ |
