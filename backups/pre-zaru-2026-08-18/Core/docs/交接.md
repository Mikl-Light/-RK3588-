## 1. 项目概述

本项目旨在为基于 **STM32F407** 的麦轮（Mecanum）四轮独立驱动小车，构建一套 ROS2 上位机控制系统。系统通过串口与下位机通信，实现：

- **速度控制**：接收 `/cmd_vel` 话题（`geometry_msgs/Twist`），转换为底盘速度矢量命令 `V`。
- **遥测反馈**：解析下位机发送的 `$T` 遥测帧，发布为 ROS2 标准话题（里程计、IMU、编码器、轮速）。
- **远程控制**：提供键盘遥控节点，支持前进、后退、横移、旋转及速度调节。
- **状态监控**：可扩展解析 `$STAT` 状态帧并发布自定义状态话题。

## 2. 硬件接口与通信协议

### 2.1 串口参数

| 参数        | 值                |
|-------------|-------------------|
| 接口        | USART2 (PD5 TX, PD6 RX) |
| 波特率      | 460800            |
| 数据位      | 8                 |
| 停止位      | 1                 |
| 校验位      | 无                |
| 流控        | 无                |
| 发送方式    | DMA 异步          |
| 命令结束符  | `\r` 或 `\n`      |

### 2.2 命令协议（下位机接收）

所有命令以回车结尾，大小写不敏感。详细命令列表参见[串口命令手册 v2.0](#)（已提供）。

**核心命令**：

| 命令格式                    | 说明                                    |
|-----------------------------|-----------------------------------------|
| `V,<Vx>,<Vy>,<Wz>`          | 设置速度矢量（右、前、逆时针）          |
| `STOP`                      | 紧急停止                                |
| `TELEM,ON` / `TELEM,OFF`    | 开启/关闭遥测流                         |
| `TELEM,<ms>`                | 设置遥测发送间隔（ms）                  |
| `ODORST`                    | 里程计归零                              |
| `ODOSET,<x>,<y>,<hdg>`      | 设置里程计位姿（米，度）                |
| `STATUS`                    | 查询状态                                |
| `M1,<RPM>` ~ `MALL,<RPM>`   | 传统电机速度控制（兼容）                |

### 2.3 遥测帧格式（下位机→上位机）

下位机主动发送 `$T` 帧（默认 50Hz），内容如下（逗号分隔）：

```
$T,<tick>,<enc1>,<enc2>,<enc3>,<enc4>,
   <ax_mg>,<ay_mg>,<az_mg>,
   <gx_dps100>,<gy_dps100>,<gz_dps100>,
   <mx_uT100>,<my_uT100>,<mz_uT100>,
   <pose_x_mm>,<pose_y_mm>,<heading_ddeg>,
   <vx_mmps>,<vy_mmps>,<omega_mradps>,
   <w1_rpm10>,<w2_rpm10>,<w3_rpm10>,<w4_rpm10>
```

字段详细说明参见[手册](#)。

### 2.4 状态帧格式（查询响应）

```
$STAT,<state>,HDG=<deg>,X=<m>,Y=<m>,DIST=<m>,REM=<m>,Vx=<mps>,Vy=<mps>,Wz=<radps>,M1=<rpm>,M2=<rpm>,M3=<rpm>,M4=<rpm>
```

## 3. 软件架构

### 3.1 ROS2 节点设计

本项目包含两个主要节点，均采用 Python 实现。

```mermaid
flowchart LR
    subgraph ROS2
        KB[键盘节点<br/>keyboard_teleop] -->|发布 /cmd_vel| BR
        BR[串口桥接节点<br/>serial_bridge] -->|订阅 /cmd_vel| BR
        BR -->|串口| MCU[下位机 STM32]
        MCU -->|$T, $STAT| BR
        BR -->|发布| ODOM[/odom]
        BR -->|发布| IMU[/imu/data_raw]
        BR -->|发布| ENC[/wheel_encoders]
        BR -->|发布| SPEED[/wheel_speeds]
        BR -->|发布| STATUS[/chassis_status]
    end
```

### 3.2 节点功能分解

#### 3.2.1 串口桥接节点 (`serial_bridge`)

- **职责**：
  - 打开/管理串口（参数可配置）。
  - 订阅 `/cmd_vel`（`geometry_msgs/Twist`），转换为 `V` 命令发送。
  - 异步接收串口数据，逐行解析 `$T` 和 `$STAT` 帧。
  - 发布解析后的数据到 ROS2 标准话题。
  - 提供 `/stop_chassis` 服务（`std_srvs/Trigger`）用于急停。

- **参数**（可配置）：
  - `port` (string) : 串口设备路径，默认 `/dev/ttyUSB0`
  - `baudrate` (int) : 波特率，默认 460800
  - `publish_odom` (bool) : 是否发布里程计，默认 true
  - `publish_imu` (bool) : 是否发布原始IMU，默认 true
  - `frame_id`, `child_frame_id` : odom坐标系名称

- **发布的话题**：
  - `/odom` (`nav_msgs/Odometry`) : 融合后的位姿 + 速度
  - `/imu/data_raw` (`sensor_msgs/Imu`) : 加速度计、陀螺仪原始数据（协方差为0）
  - `/wheel_encoders` (`std_msgs/Int32MultiArray`) : 四个编码器增量（每个周期）
  - `/wheel_speeds` (`std_msgs/Float32MultiArray`) : 四个轮子实际转速（RPM）
  - （可选） `/chassis_status` (自定义消息) : 来自 `$STAT` 的解析结果

- **订阅的话题**：
  - `/cmd_vel` (`geometry_msgs/Twist`) : 速度指令

- **提供的服务**：
  - `/stop_chassis` (`std_srvs/Trigger`) : 发送 `STOP` 命令

- **坐标系转换**：
  - ROS 标准：X 前，Y 左，Z 上。
  - 底盘 `V` 命令：Vx 右，Vy 前，Wz 逆时针。
  - 转换公式：`Vx = -linear.y`，`Vy = linear.x`，`Wz = angular.z`。

#### 3.2.2 键盘遥控节点 (`keyboard_teleop`)

- **职责**：读取键盘输入，发布 `/cmd_vel` 实现速度控制。
- **按键映射**（可自定义）：
  - `W` : 前进 (+linear.x)
  - `S` : 后退 (-linear.x)
  - `A` : 左移 (+linear.y)
  - `D` : 右移 (-linear.y)
  - `Q` : 左旋转 (+angular.z)
  - `E` : 右旋转 (-angular.z)
  - `Space` : 紧急停止 (发布零速度)
  - `+` / `-` : 增加/减少速度倍率 (0.1~5.0)
- **发布频率**：10Hz（限频）。
- **参数**：
  - `linear_vel` : 默认前进/横移速度 (m/s)
  - `angular_vel` : 默认旋转速度 (rad/s)
  - `linear_step` / `angular_step` : 按键速度步进（暂未使用，可扩展）

### 3.3 依赖与系统要求

- **操作系统**：Ubuntu 24.04 (Noble)

## 5. 部署与运行指南

### 5.1 环境搭建

```bash
# 1. 安装 ROS 2 Jazzy（参考官方文档）
# 2. 安装 Python 依赖
sudo apt install python3-serial python3-pynput
# 或使用 pip（确保对应 python3.12）
python3 -m pip install pyserial pynput

# 3. 创建工作空间（假设为 ~/ros2_ws）
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws/src
# 创建功能包
ros2 pkg create --build-type ament_python mecanum_bringup
```

### 5.2 代码放置

将 `serial_bridge.py` 和 `keyboard_teleop.py` 放入 `mecanum_bringup/scripts/` 目录，并添加可执行权限：

```bash
chmod +x ~/ros2_ws/src/mecanum_bringup/scripts/*.py
```

将 launch 文件放入 `mecanum_bringup/launch/`。

### 5.3 编译与运行

```bash
cd ~/ros2_ws
colcon build --packages-select mecanum_bringup
source install/setup.bash

# 运行（默认端口 /dev/ttyUSB0）
ros2 launch mecanum_bringup mecanum_control.launch.py port:=/dev/ttyACM0
```

### 5.4 测试

- 使用键盘控制小车运动。
- 查看遥测话题：`ros2 topic echo /odom`
- 发送外部指令：`ros2 topic pub /cmd_vel geometry_msgs/Twist "{linear: {x: 0.2}, angular: {z: 0.5}}"`
- 急停：`ros2 service call /stop_chassis std_srvs/Trigger`

## 6. 维护与扩展建议

### 6.1 可能的问题与调试

- **串口权限**：将用户加入 `dialout` 组：`sudo usermod -a -G dialout $USER`
- **无遥测数据**：检查下位机是否发送 `$T`（可先用串口助手查看）；确认波特率一致。
- **速度反向**：检查坐标系转换公式，根据实际电机安装调整符号。
- **键盘监听失效**：确保在终端中运行（非后台），且未与其他键盘监听冲突。

### 6.2 扩展方向

- **添加导航模式**：支持 `N/E/S/W/DIR` 命令，可创建 Action 服务器实现带反馈的导航任务。
- **增强里程计**：使用 `robot_localization` 包融合更多传感器（如 GPS 等）。
- **参数动态调整**：通过 ROS2 参数动态修改 PID、速度限制等，并发送相应命令。
- **多机支持**：增加命名空间或节点名称参数。
- **日志记录**：将遥测数据记录为 bag 文件以供离线分析。

### 6.3 与下位机联调建议

- 先用串口助手（如 `screen /dev/ttyUSB0 460800`）手动发送 `V,0.0,0.2,0.0` 测试运动。
- 确认 `TELEM,ON` 后能收到 `$T` 帧。
- 逐步启动 ROS2 节点，观察话题数据。
