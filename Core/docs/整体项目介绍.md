## 1. 项目一句话

一辆 **STM32F407 驱动的四轮麦轮（Mecanum）小车**，板载 9 轴 IMU（MPU9250）、四路编码器、TB6612 电机驱动，可任意方向平移、原地旋转、速度闭环；上位机由 **RK3588（Ubuntu 24.04 + ROS2 Jazzy）** 承担，负责串口桥接、激光 SLAM 建图、自主导航、摄像头与手机端访问。

```
┌──────────────────────────────────────────────────────────────────────┐
│                    微信小程序 / Web 浏览器                             │
│                  HTTP (inspector_web，默认 8765)                      │
└───────────────────────────┬──────────────────────────────────────────┘
                            │
┌───────────────────────────▼──────────────────────────────────────────┐
│                 RK3588 上位机 (Ubuntu 24.04 + ROS2 Jazzy)              │
│  ┌─────────────────────┐  ┌─────────────┐  ┌──────────────────────┐  │
│  │ inspector_web       │  │ slam_toolbox│  │ nav2                 │  │
│  │ ROS↔HTTP 出口       │  │ 激光 SLAM   │  │ 路径规划/控制         │  │
│  └──────────┬──────────┘  └──────┬──────┘  └──────────┬───────────┘  │
│             │                    │                    │              │
│  ┌──────────▼────────────────────▼────────────────────▼───────────┐  │
│  │ warehouse_inspector  (现场主栈)                                 │  │
│  │  chassis_bridge · scan_filter · map_despeckle · 导航/巡检/绕圆   │  │
│  └──────────────────────────┬─────────────────────────────────────┘  │
│                             │                                        │
│  rplidar_ros → scan_raw ────┤──── rf2o → /odom_laser ─┐              │
│                             │                         ├→ odom_fusion │
│                    chassis_bridge → /odom (轮式) ─────┘   → /odom_fused│
└─────────────────────────────┼────────────────────────────────────────┘
                              │ USART2 460800 8N1（PD5 TX / PD6 RX）
┌─────────────────────────────▼────────────────────────────────────────┐
│                    STM32F407ZGT6（裸机 168MHz）                        │
│   uart_io · mpu9250 · ahrs · odometry(EKF) · chassis · motor · telemetry│
└──────────────────────────────────────────────────────────────────────┘
```

## 2. 硬件

| 部件 | 型号/参数 |
|---|---|
| 主控 | STM32F407ZGT6 @ 168MHz（8MHz HSE，PLLM=4 / N=168 / P=2） |
| 底盘 | 麦轮四驱，轮径 **80 mm**，Lx = Ly = 75 mm |
| 电机 | MC520P30_12V ×4（13 线编码器 / 30:1 减速，输出轴 52 cnt/rev） |
| 驱动 | TB6612 ×2 |
| IMU | MPU9250（实为 MPU6500 内核，WHO_AM_I = 0x70），I2C1 100kHz |
| 雷达 | RPLIDAR C1，USB `/dev/ttyUSB0` 460800，**0° 在车尾** |
| 上位机 | RK3588 / Ubuntu 24.04 / ROS2 Jazzy / 8 核 16G |
| 相机 | DH-200W-X1（USB2.0 UVC，MJPG 1080p30） |

## 3. 分层职责

### 3.1 固件（`Core/Src`，全裸机轮询 + 中断，无 RTOS）

| 模块 | 文件 | 职责 |
|---|---|---|
| 串口驱动 | `uart_io.c/.h` | TX 2048B 环形 + DMA1 Stream6 异步发送；RX 中断环形；printf 重定向 |
| 调试日志 | `debug.c/.h` | 5 级日志（NONE~VERBOSE），带时间戳 + 模块名 |
| IMU 驱动 | `mpu9250.c/.h` | 九轴采集、校准、I2C 故障自恢复；硬磁/软磁参数预置在 `mpu9250.h` |
| 航向融合 | `ahrs.c/.h` | 陀螺 + 磁互补滤波（α=0.98）、ZARU 零偏再估计、相位滞后补偿 |
| 里程计 | `odometry.c/.h` | 麦轮正运动学 + EKF + 监督层（动态 Q）+ ZUPT |
| 底盘 | `chassis.c/.h` | 麦轮逆运动学 + 状态机（IDLE/TURNING/MOVING/MANUAL/DONE） |
| 电机 | `motor.c/.h` | 编码器测速 + 增量式 PID 速度闭环 + PWM/TB6612 |
| 遥测 | `telemetry.c/.h` | ASCII `$T`（30 字段）/ 二进制帧（112B），50Hz |
| OTA | `ota.c/.h` | 版本查询 + 升级标记 → 软复位进 Bootloader |
| 命令入口 | `main.c` | 串口命令解析分发、主循环 |

### 3.2 上位机（`tools/ros2_ws/`，车上在跑）

| 包 | 节点 | 职责 |
|---|---|---|
| `warehouse_inspector` | `chassis_bridge` | **串口桥**：解析 407 遥测 → `/odom`、`/imu/*`；`/cmd_vel` → `V` 命令；带 0.5s 看门狗 |
| `warehouse_inspector` | `scan_filter` | 雷达最小距离过滤（`angle_offset_deg` **必须为 0**，反装补偿在 TF） |
| `warehouse_inspector` | `map_despeckle` | 地图除噪（`/map_raw` → `/map`） |
| `warehouse_inspector` | — | `slam_params.yaml` / `nav2_params.yaml` / `inspection.launch.py` |
| `odom_fusion` | `fusion_node` | **全车唯一 odom 广播者**：位置取激光绝对位姿、航向取激光+磁增量加权 → `/odom_fused` + TF |
| `rf2o_laser_odometry` | `rf2o_laser_odometry_node` | 激光里程计 → `/odom_laser`（**不发 TF**） |
| `rplidar_ros` | `rplidar_node` | 雷达驱动，**必须传 `-p topic_name:=scan_raw`** |
| `robot_gui_ng` | — | Web 可视化控制中心（单端口，浏览器直开） |
| `camera_bringup` | `mjpeg_camera_node` | USB 相机 MJPG 采集 |
| `traffic_sign_control` | — | 交通标志识别 → 底盘动作 |

> `inspector_web`（手机端 HTTP 出口）在车上运行时存在，**但本仓库未收录源码**。

`tools/legacy/` 下是已停用的旧方案（`mecanum_bringup` 的 `serial_bridge`、`mecanum_bringup_hector`、
`robot_gui`、`odom_compare_web`），**与新链路冲突，不要同时启动**。

### 3.3 ROS2 关键话题

| 话题 | 类型 | 内容 |
|---|---|---|
| `/odom_fused` | nav_msgs/Odometry | **全车唯一 odom**，slam_toolbox / nav2 都用它 |
| `/odom_laser` | nav_msgs/Odometry | rf2o 激光里程计（融合的位置来源） |
| `/odom` | nav_msgs/Odometry | 固件 EKF 位姿（**位置是固件世界系，与 ROS 系差 90°，勿直接混用**） |
| `/scan_raw` → `/scan` | sensor_msgs/LaserScan | 雷达原始 → 过滤后 |
| `/cmd_vel` | geometry_msgs/Twist | 速度指令（`linear.x` = 前进 m/s） |
| `/imu/imu407/data_raw` | sensor_msgs/Imu | 原始 IMU 转 SI |
| `/imu/imu407/mag` | sensor_msgs/MagneticField | 磁力计（**数值被放大 10000 倍，用前除回**） |
| `/map_raw` → `/map` | nav_msgs/OccupancyGrid | slam 原始图 → 除噪后 |
| `/image_raw/compressed` | sensor_msgs/CompressedImage | 摄像头压缩图 |

**TF 树**：`map → odom_fused → base_link → laser`（`base_link→laser` 含 `yaw = π`，补偿雷达反装）

## 4. 客户端怎么接

客户端（App / 小程序 / Web）**不碰串口，也不直接对接 ROS**。链路是：

```
客户端 ──HTTP──> inspector_web (RK3588, 默认 8765) ──ROS──> warehouse_inspector ──串口──> STM32
```

**接口细节与字段定义，以 `client/wechat-miniprogram/README.md` 为准**（它随后端同步维护）。
这里只列三条硬约束：

1. **不要发 `ODORST` / `TELEM,ON` / `LINE_FOLLOW_*`** —— 当前后端里这些命令**已不存在**。
2. **速度必须软限幅**：`Vx/Vy ≤ 0.50 m/s`，`Wz ≤ 1.50 rad/s`（后端也限，但客户端别依赖）。
3. **急停常驻**：松手、断线、轮询超时 > 2s 都要立即发停车。

> 微信小程序 `wx.request` 正式版只允许 HTTPS 域名。开发时在开发者工具勾选"不校验合法域名"，
> 正式发布需为后端配 HTTPS 或改 WSS。同一局域网下手机直连 RK3588 IP 即可。

### 坐标系与单位（务必与车一致）

```
机器人系: X = 前, Y = 左, 旋转逆时针为正      ← 已 ROS 化，2026-08-12 起
世界系:   X = 北(开机朝向), Y = 西
/odom_fused 的 yaw 单位弧度，0 = 开机时车头方向  ← 不含地理朝向
V 命令:   V,<前/后 m/s>,<左/右 m/s>,<旋转 rad/s>
```

## 6. 部署步骤（RK3588）

```bash
# 1. 串口权限
echo 'KERNEL=="ttyS1", MODE="0666"' | sudo tee /etc/udev/rules.d/99-ttyS1.rules
sudo udevadm control --reload && sudo udevadm trigger

# 2. 编译
cd ~/ros2_ws && source /opt/ros/jazzy/setup.bash
colcon build --packages-select warehouse_inspector odom_fusion

# 3. 起建图链路（不启 nav2 / 巡检 / 绕圆）
ros2 launch warehouse_inspector inspection.launch.py nav2:=false inspection:=false circle:=false

# 4. 起手机端出口
ros2 launch inspector_web web.launch.py          # 默认 8765

# 5. 验证
#    浏览器 http://<RK3588_IP>:8765/
#    防火墙: sudo ufw allow 8765/tcp
```

**起之前先数节点**：`ps -ef | grep -c '[r]plidar_node'` 必须是 0。
多个实例抢 `/dev/ttyUSB0` 会让 `/scan` 直接消失，而且现场看起来"什么都没报错"。
后台起 launch 用 `setsid`，否则 SSH 断开会连带杀掉。
