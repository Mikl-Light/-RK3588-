> 保留本文是因为它把"串口帧 ↔ ROS 话题"的转换逻辑讲得最清楚，原理对新桥同样适用。

```text
tools/legacy/mecanum_bringup/mecanum_bringup/serial_bridge.py
```

## 1. 作用

```text
STM32F407 串口数据 <-> ROS2 话题
```

## 2. 数据流

```text
STM32 串口
   ↓
rx_loop() 自动识别 ASCII / 二进制
   ↓
process_line / unpack_binary
   ↓
publish_binary()
   ↓
/odom
/imu/imu407/*
/wheel_encoders
/wheel_speeds
/stm32_tick
/chassis_status
```

反向：

```text
/cmd_vel
   ↓
cmd_vel_cb()
   ↓
发送 V,<vx>,<vy>,<wz>
```

## 3. 关键类

```python
class SerialBridge(Node):
```

### 3.1 初始化

```python
declare_parameter('port', '/dev/ttyS1')
declare_parameter('baudrate', 460800)
create_publisher(Odometry, '/odom')
create_publisher(Imu, '/imu/imu407/data_raw')
create_subscription(Twist, '/cmd_vel', cmd_vel_cb)
```

### 3.2 串口接收线程

```python
self.rx_thread = threading.Thread(target=self.rx_loop)
```

### 3.3 二进制帧解析

```python
unpack_binary(buf):
    0xAA55 校验
    CRC8 校验
    struct.unpack 解析
```

### 3.4 发布 odom + TF

```python
odom.header.frame_id = 'odom'
odom.child_frame_id = 'base_link'
tf_broadcaster.sendTransform()
```

## 4. 坐标系

```text
ROS 约定：
x = 前
y = 左
z = 逆时针

固件 V2.x 已经 ROS 化，桥直通。
yaw 转换：
    ROS yaw = -heading
```

## 5. QoS 注意

- 摄像头原始图像使用 RELIABLE，因为 web_video_server 需要。
- 激光/里程计常用 sensor data QoS。
- 如果出现“incompatible QoS”，优先检查发布/订阅可靠性策略。

## 6. 常见调试

```bash
ros2 topic echo /odom --once
ros2 topic echo /imu/imu407/data_raw --once
ros2 topic hz /odom
ros2 node info /serial_bridge
```
