# 02 STM32 外设驱动

## 1. 定时器：TIM1/3/4/8 编码器 + TIM2 PWM

### 1.1 编码器模式

文件：

```text
Core/Src/tim.c
Core/Src/motor.c
```

每个电机使用一个定时器作为编码器接口：

```text
M1: TIM1  编码器
M2: TIM3  编码器
M3: TIM4  编码器
M4: TIM8  编码器
PWM: TIM2  CH1~CH4
```

编码器原理：

```text
AB 相正交编码
定时器自动计数
→ 读取 CNT 得到角度增量
→ 通过方向判断正转/反转
```

### 1.2 电机初始化

`motor.c` 中每个电机保存：

```c
typedef struct {
    TIM_HandleTypeDef *htim_encoder;
    TIM_HandleTypeDef *htim_pwm;
    int8_t  direction_sign;   // 编码器方向符号
    int32_t count_delta;      // 本周期计数增量
    float   speed_rpm;        // 当前 RPM
    float   position;         // 累计位置（圈）
    PID_Controller pid_speed; // 速度环 PID
} Motor_Handle;
```

关键函数：

```c
Motor_InitAll()        // 初始化 4 个电机
Motor_UpdateAll(dt)    // 每个周期更新编码器、RPM、PID
Motor_SetAllSpeeds()   // 设置 4 轮目标 RPM
```

### 1.3 速度计算

```c
speed_rpm = 编码器增量 / 单位时间 / 编码器每转计数值 * 减速比 * 60
```

方向符号 `direction_sign` 用来修正编码器接线反相。

## 2. PWM 输出

TIM2 四路 PWM 驱动电机驱动芯片：

```c
MOTOR1: TIM2_CH1
MOTOR2: TIM2_CH2
MOTOR3: TIM2_CH3
MOTOR4: TIM2_CH4
```

控制模式：

```c
MOTOR_MODE_OPEN_LOOP  // 开环：直接设置占空比
MOTOR_MODE_SPEED      // 闭环：PID 输出 PWM
```

## 3. 串口 USART2

文件：

```text
Core/Src/usart.c
Core/Src/uart_io.c
```

### 3.1 配置

```text
USART2
PD5 = TX
PD6 = RX
460800 8N1
TX DMA
```

### 3.2 环形缓冲区

`uart_io.c` 实现：

```text
RX 中断 -> 环形缓冲区
主循环读取 UART_IO_GetChar()
```

关键变量：

```c
uint8_t rx_buf[RX_BUF_SIZE];
uint16_t rx_head, rx_tail;
```

### 3.3 printf 重定向

```c
UART_IO_Printf("...");
```

内部本质是：

```c
将字符串通过 DMA 或阻塞发送到 USART2
```

## 4. I2C1：MPU9250

文件：

```text
Core/Src/i2c.c
Core/Src/mpu9250.c
```

I2C 配置：

```text
I2C1
PB8 = SCL
PB9 = SDA
100kHz
```

### 4.1 I2C 安全读写

`mpu9250.c` 封装了：

```c
I2C_SafeRead()
I2C_SafeWrite()
I2C_Recover()
```

作用：

- I2C 超时快速失败
- 连续失败自动恢复总线
- 防止电机 EMI 导致 I2C BUSY 卡死

### 4.2 MPU9250 初始化

```c
MPU9250_Init(GYRO_FS_250, ACCEL_FS_2G, DLPF_42HZ, MAG_MODE_CONT_100HZ);
```

初始化流程：

```text
复位 MPU9250
验证 WHO_AM_I
配置陀螺仪量程
配置加速度计量程
配置 DLPF
初始化 AK8963 磁力计
```

### 4.3 陀螺仪快速读取

```c
MPU9250_ReadGyro(&gx, &gy, &gz);
```

只读 6 字节，比 `ReadAll` 快，用于 AHRS 高频更新。

## 5. 数据换算

### 加速度计

```c
accel_g = raw / 16384.0f   // ±2g
```

### 陀螺仪

```c
gyro_dps = raw / 131.0f    // ±250dps
```

### 磁力计

```c
mag_uT = raw * 0.15f * asa - offset
```

注意：磁力计当前有轴映射和标定问题，详见 `03-控制与算法.md`。
