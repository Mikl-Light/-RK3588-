# 07 ROS2 建图与导航

## 1. 建图方案

### 1.1 当前主要方案

```text
RPLIDAR C1 -> /scan
rf2o_laser_odometry -> /odom_laser
slam_toolbox -> /map + map -> odom_laser
```

### 1.2 为什么用激光里程计

```text
轮式里程计在麦轮打滑/横移时误差大
激光里程计直接用雷达匹配，减少里程计误差对建图影响
```

### 1.3 雷达方向问题

已修正：

```text
base_link -> laser
x=0.13
yaw=3.14159
```

## 3. Nav2 核心概念

```text
map_server    加载地图
AMCL          定位
planner_server 全局规划
controller_server 局部控制
behavior_server 恢复行为
bt_navigator  行为树导航
```

## 4. Nav2 Jazzy 注意事项

- `nav2_recoveries` 已改名 `nav2_behaviors`
- 可执行文件是 `behavior_server`
- 插件名使用 `::`：
  ```yaml
  plugin: "nav2_navfn_planner::NavfnPlanner"
  plugin: "nav2_behaviors::Spin"
  ```
- costmap `width/height` 必须是整数
- map_server 需要调用 `/map_server/map` 才发布地图
- `map_trigger.py` 会自动持续发布 `/map`

## 5. 关键节点

### 5.1 map_trigger

```text
调用 /map_server/map
拿到 OccupancyGrid
1Hz 持续发布 /map
自动触发 AMCL 全局重定位
```

### 5.2 goal_pose_bridge

```text
订阅 rviz2 的 /goal_pose
转发给 /navigate_to_pose action
```

### 5.3 keyboard_teleop_hector

```text
修复了原版 + / - 崩溃问题
支持 W/S/A/D/Q/E 组合
SSH stdin 模式
```

## 6. 参数文件

```text
config/nav2_params.yaml
```

重要参数：

```yaml
controller_server:
  FollowPath:
    plugin: "nav2_regulated_pure_pursuit_controller::RegulatedPurePursuitController"
    allow_reversing: false
    use_rotate_to_heading: true
```
