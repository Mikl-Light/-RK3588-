# 03 控制与算法

## 1. PID 控制器

文件：

```text
Core/Src/pid.c
Core/Inc/pid.h
```

PID 结构：

```c
typedef struct {
    float kp, ki, kd;
    float integral;
    float prev_error;
    float out_min, out_max;
} PID_Controller;
```

调用流程：

```c
PID_Compute(&pid, target, feedback, dt);
```

输出限幅：

```c
out = Kp*err + Ki*integral + Kd*(err - prev_err)
if (out > out_max) out = out_max;
if (out < out_min) out = out_min;
```

用途：

```text
每个电机速度环
底盘转向 PID
```

## 2. 麦轮运动学

文件：

```text
Core/Src/chassis.c
```

### 2.1 逆运动学（速度 -> 轮速）

```c
w[0] = ( vx - vy - omega * L) / R;  // FL
w[1] = ( vx + vy + omega * L) / R;  // FR
w[2] = ( vx + vy - omega * L) / R;  // RL
w[3] = ( vx - vy + omega * L) / R;  // RR
```

含义：

```text
vx   = 前后速度
vy   = 左右速度
omega = 旋转角速度
L = Lx + Ly
R = 轮半径
```

### 2.2 状态机

```c
CHASSIS_STATE_IDLE
CHASSIS_STATE_MANUAL
CHASSIS_STATE_TURNING
CHASSIS_STATE_MOVING
CHASSIS_STATE_DONE
```

核心命令：

```c
Chassis_MoveMecanum(vx, vy, omega);
```

## 3. 里程计

文件：

```text
Core/Src/odometry.c
```

### 3.1 正向运动学（轮速 -> 速度）

```c
Vx = R/4 * (w1 + w2 + w3 + w4)          // 前
Vy = R/4 * (-w1 + w2 + w3 - w4)         // 左
Wz = R/(4L) * (-w1 + w2 - w3 + w4)      // 旋转
```

### 3.2 航位推算

```c
heading_rad = -heading * PI / 180;   // 罗盘角 -> ROS yaw

dx = (Vx*cos - Vy*sin) * dt;
dy = (Vx*sin + Vy*cos) * dt;

x += dx;
y += dy;
```
