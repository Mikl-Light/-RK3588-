## 2. STM32 App 启动流程

入口文件：

```text
Core/Src/main.c
```

### 2.1 启动顺序

```c
main()
├── __enable_irq();          // 防止 Bootloader 跳转后中断被关闭
├── HAL_Init();              // 初始化 SysTick、Flash、中断优先级
├── SystemClock_Config();    // HSE + PLL -> 168MHz
├── MX_GPIO_Init();
├── MX_TIM1_Init();          // 编码器 M1
├── MX_TIM2_Init();          // PWM 所有电机
├── MX_TIM3_Init();          // 编码器 M2
├── MX_TIM4_Init();          // 编码器 M3
├── MX_TIM8_Init();          // 编码器 M4
├── MX_USART2_UART_Init();   // 460800 8N1
├── MX_I2C1_Init();          // 接 MPU9250
├── UART_IO_Init();          // printf 重定向 + 环形缓冲区
├── Debug_Init();
├── Motor_InitAll();         // 初始化 4 个电机
├── MPU9250_Init();          // 初始化 9 轴 IMU
├── MPU9250_CalibrateGyro(); // 陀螺仪零偏校准
├── AHRS_Init();             // 航向初始化
├── Chassis_Init();          // 麦轮底盘初始化
├── Odom_Init();             // 里程计初始化
├── Telemetry_Init();        // 遥测初始化（默认关闭）
└── while(1) { 主循环 }
```

### 2.2 主循环 10ms 任务

```c
while (1)
{
    1. 读取串口命令并解析
    2. 计算实际控制周期 dt
    3. ZARU 静止检测
    4. AHRS_Update(dt)        // 更新航向
    5. Odom_Update(dt)        // 更新里程计
    6. Chassis_Update(dt)     // 更新底盘状态机
    7. Motor_UpdateAll(dt)    // 更新电机 PID + PWM
    8. Telemetry_Update()     // 发送遥测
    9. ReportStatus()         // 500ms 状态上报
    10. LED 闪烁
    HAL_Delay(10);
}
```

## 3. Bootloader 跳转流程

Bootloader 位于：

```text
tools/Bootloader/Core/Src/main.c
```

启动流程：

```c
HAL_Init();
SystemClock_Config();
MX_GPIO_Init();
MX_USART2_UART_Init();

if (按键按下) 进入升级模式;
if (升级标记有效) 进入升级模式;
if (App 有效) BL_JumpToApp();
否则停在升级模式;
```

### 3.1 App 有效性检查

```c
uint8_t BL_AppValid(void)
{
    sp = *(uint32_t *)0x08010000;        // 栈顶指针
    pc = *(uint32_t *)(0x08010000 + 4);  // 复位向量
    if (sp 不在 SRAM 范围) return 0;
    if (pc 不在 App Flash 范围) return 0;
    if (pc 不是 Thumb 地址) return 0;
    return 1;
}
```

### 3.2 跳转前工作

```c
HAL_UART_DeInit();
HAL_RCC_DeInit();
HAL_DeInit();
SysTick 关闭;
关闭所有中断;
SCB->VTOR = 0x08010000;   // 重定位向量表
__set_MSP(sp);            // 设置主栈指针
__enable_irq();           // 恢复中断
app_reset();              // 跳到 App 复位函数
```

## 4. 数据流

```text
编码器/IMU
   ↓
Motor / MPU9250
   ↓
Odom_Update -> pose.x/y/heading/vx/vy/wz
   ↓
Telemetry_Update
   ↓
串口 $T / 二进制帧
   ↓
RK3588 serial_bridge
   ↓
/odom /odom_laser /imu 话题
   ↓
slam_toolbox / Nav2 / Web
```

---

## 5. 关键点

- App 不是从 `0x08000000` 启动，而是从 `0x08010000`。
- 向量表偏移在 `system_stm32f4xx.c`：

```c
#define VECT_TAB_OFFSET 0x00010000U
```

- 串口波特率是 `460800 8N1`。
- 主循环是裸机轮询，没有 RTOS。
