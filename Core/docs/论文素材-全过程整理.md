## 一、项目一句话与四个阶段

从"能遥控走"一路做到"能自主建图、导航、并把结果送回手机端"，
最终目标定位为**温室作物巡检平台**。

## 三、Mikl 提出的方案与方法（**论文核心章节**）

> 这一节只收【Mikl】的方案。每条的格式是：
> **背景问题 → Mikl 提了什么 → 为什么这么想 → 结果**。

### ① 增量加权融合：绕开"磁北 vs 激光首帧"的基准差 【Mikl，2026-10-20】★

**背景**：Mikl 要求磁力计参与航向融合，让车知道真实朝向。但立刻撞上一个硬矛盾——
磁力计给的是**绝对磁北**，rf2o 激光里程计给的是**相对开机首帧**，两者基准差一整段常数（实测约 310°）。
直接加权平均？不可能，差 310° 的两条线平均出来是无意义的。

**Mikl 提的方案**：**只融增量，不融绝对值**。

```
yaw_fused = 上一帧 + (w_wheel · Δyaw_wheel + w_laser · Δyaw_laser),  w_wheel + w_laser = 1
```

**为什么这么想**：基准常数在**帧间差分里自动消掉**——两边都减掉自己的上一帧，那个 310° 就没了。
剩下的只有"这一帧转了多少"，这是两个传感器都说得清的量。

**结果**：矛盾当场消失。这个思路后来一直沿用到位置融合与坐标系统一（见第 ⑧ 条的延伸）。

> 论文写法建议：这是一个**方法论层面的贡献**——"用增量域规避多源融合的基准失配"，
> 比具体公式更有价值，可以推广到任何"绝对基准 + 相对基准"的融合场景。

### ② 复查粒度从"株级"降为"行级"：主动把需求降一个数量级 【Mikl，2026-10-23】★

**背景**：项目需要复查——"过几天回来找同一处病害"。Mikl 最初的要求是**精确到株**
（"这株番茄是 B3 垄第 42 株"），由此引出株级计数、漏检一株则后续全部错位、
每 10 株一个锚定牌、株级视觉重识别（本来就不可行）等一整套脆弱方案。

**Mikl 提的方案**：**不记具体植株，只记这一行（或这一列），复查时整行全查**。

**为什么这么想**：株级方案存在**唯一一个"错一次就永久错"的环节**——计数。
而行级方案里，行内误差只影响本行，**不会跨行累积**。用"多做一次完整扫描"的重复劳动，
换掉"必须精确计数"的脆弱假设。

**结果**：整条技术路线的复杂度断崖式下降：

| 株级需要 | 行级还需要 |
|---|---|
| 计数准确率 > 99% | 不需要 |
| 每 10 株一个锚定牌 | 降到每行 1 块，甚至不需要 |
| 株级视觉重识别 | 不需要 |

### ③ 坚持"建图 + 地图内规划"，否决硬编码路径 【Mikl，2026-10-23】★

**背景**：AA 当时的建议是——既然场地只有两条臂（L 形），
就直接写一条"走完→转角→再走"的**固定路径**，把 SLAM / nav2 全砍掉，代码几百行。
这条建议在"行数固定"的前提下是对的。

**Mikl 否掉了它，理由三条**：
1. **通用性**：行数从 2 变 30，固定路径方案要重写；建图方案零成本
2. **定位方式**：固定路径靠**累积里程**，误差单调增长；建图方案靠**绝对匹配**，误差不累积
3. **复查本质**：有了稳定地图和重定位，**坐标本身就是"同一个地方"的最强定义**，
   连带把"能不能在垄头插牌""怎么数株"这些纠结一起消掉

**结果**：方案反转，定为"建图 + 地图内规划"。并且——
**"地图会过期"是这套方案在农业场景的真实代价**（作物会长），
对策是只依赖稳定结构（槽壁、立柱、墙）、定期重建，这一点也一并定下。

> 论文写法建议：这条是**方案选型的论证过程**，本身就是一个可写的技术判断，
> 而且它体现了"通用性 vs 针对性"的权衡，评委通常喜欢看这种。

### ④ 用"麦轮四项地面要求"否决麦轮，转差速 【Mikl，2026-10-23】★

**背景**：AA 一度说"温室走道多为砖或混凝土，麦轮能用"，把麦轮保住了。

**Mikl 反问了一句**："难道温室地面就很适合麦轮吗？"

**这一问直接推翻了 AA 的结论**，并收敛出**麦轮成立的四项必要条件**：

| 麦轮要求 | 温室现实 |
|---|---|
| 不塌陷（侧向刚度高） | 素土、稻壳覆盖、松散床土 → 塌陷 |
| 缝隙 < 5 mm 且无凸起 | 砖铺走道缝就有 5~10 mm，辊子卡缝 |
| 无坡度 | 温室普遍 0.5~1% 排水坡 |
| 干燥、高摩擦 | 湿度 70~95%，砖缝青苔湿滑 |

**更深一层的判断（这条最有价值）**：
麦轮的横移精度**完全建立在"侧向不打滑"这个默认前提上**。
横移时辊子必然侧滑，编码器只测得到轮子转动、测不到车身真实侧移——
**侧滑对麦轮而言是"不可观测误差"**，系统默认它为零。干燥混凝土上这个默认勉强成立，
潮湿青苔地面上，侧滑可能占总横移量的很大比例，而里程计完全不知道。

**结果**：麦轮出局。随后再加一条 —— **温室里根本不需要横移**，

### ⑧ 找到"磁力计能不能用"的真正答案：区分原地与平移 【共同，2026-10-22】

**背景**：一个长期自相矛盾的结论——原地转圈测出闭环误差 **0.30°**（很准），
但直线走 3 s 航向就偏 **4.3°**（很烂）。谁对？

**Mikl 提供的观测**：往返之后车停的角度与最初差约 +10°。（Mikl 是最先注意到该异常的人）

**逐步查出的答案**（这条的推导过程比结论更值钱）：
- 陀螺积分 3 s 只有 +0.214° → **陀螺无罪**
- −4.3° 里 **−4.514° 全部来自磁修正**
- 停车后电机断电，`magx` **没有回到原值而是继续下降** → **与电流无关**
- 手推回原位（电机完全不通电），读数**回到 23.78** → **与位置绑定**
- 梯度 21 µT/m，而地磁水平分量只有 18.83 µT → 房间磁场极不均匀

**最终结论（可直接写进论文）**：
> **"判圈 0.30°"与"直线 4.3°"同时为真，并不矛盾**——
> 前者是原地旋转（位置不变，磁场稳定），后者是平移（位置变化，磁场随之变化）。
> **不能拿原地旋转的精度去推断平移工况的精度。**

这一条纠正了整个项目前期对磁力计的评估方法。

### ⑩ 设计"分阶段逐轮加电"的磁干扰量化实验 【Mikl，2026-10-18】★

**背景**：需要知道"电机到底干扰磁力计多少"。在此之前，AA 的习惯是一有磁跳变就往电机上归因。

**Mikl 设计的实验**：前 50 s 每 10 s 加一个轮（无 → M1 → M1+M3 → M1+M2+M3 → 四轮），
各采 10 s 磁力计数据；50 s 后四轮不关，旋转车身一圈判满。

**为什么这个设计是对的**：它把"干扰源"做成了**唯一变量、单调递增**，
如果干扰来自电机，\|B\| 和磁航向必须随轮数单调变化；如果是外部铁磁体（手机），
则表现会是无规律的**跳变**。这样一次实验就能区分两种假设。

**结果**：\|B\| 54.1 → 51.8 µT（−4%），航向 310.4 → 306.8°（−3.6°），
**单调、无跳变** → 电机干扰 ~4% 磁场 / ~3.6° 航向，工程上可忽略；
真正的元凶是**外部铁磁体（手机）**。

## 五、可写进论文的贡献点

### 5.1 Mikl 可以主张的三类贡献

**① 系统级工程贡献（最扎实、最容易写）**
> Mikl 主导构建了资源受限的嵌入式 + ROS2 异构平台上"固件—串口桥—激光里程计—融合—SLAM—导航—移动端"
> 的完整链路，并通过**自建的多重独立裁判**（点云几何互相关、位姿自洽性检验、三路航向对比）
> 系统性地排除了一个**多层叠加的航向/里程计误差链**——
> 这条误差链由 5 个相互掩盖的缺陷组成：雷达反装 180°、轮径写错、磁标定失效、
> 互补滤波结构性滞后、yaw 符号反向。任何一个单独存在都会让定位失效，
> 而它们彼此掩盖（详见 5.3）。

**② 方法贡献：增量域融合**
> 针对"绝对基准（磁北）与相对基准（激光首帧）不可直接加权"的问题，
> Mikl 提出**在增量域融合**的做法：只对帧间变化量加权，基准常数在差分中自动消去。
> 该思路随后被扩展到位置与坐标系的选择上。

**③ 应用贡献：面向温室的巡检需求重构**
> Mikl 把复查粒度从"精确到株"降级为"按行复查"，把定位问题从**累积计数**转化为**地图坐标 + 重定位**；
> 并据此论证麦轮机构在温室不成立（侧滑为不可观测误差），给出差速四轮 + 大轮径的选型依据。

### 5.3 最有说服力的一条叙事：**误差互相掩盖**

这是本项目最值得写的东西，因为它解释了"为什么这些 bug 能活一个多月"：

| 缺陷 | 为什么单独看不出来 |
|---|---|
| 雷达反装 180° | 室内四周都有墙，任何方向都能读到距离，**看起来"有数据"就是"正常"** |
| 轮径写错 21% | 没有**独立长度基准**时，"走得对不对"只能靠里程计自己说，是循环论证 |
| yaw 符号反向 | **直线时 yaw 几乎不变**，符号反不反都一样；**反向转 360° 也会回到同一读数**，闭环测试同样无效。只有整体旋转能暴露 |
| 磁标定失效 | 磁数据**是死的**，死数据上做任何测试都自洽 |
| 互补滤波 0.5 s 滞后 | 只在**变速转弯**时暴露，匀速转弯看不出来 |

**共性**：这些缺陷都属于"**测量系统自身无法自证**"的类型。
**破局的办法不是更努力地调参，而是造独立裁判**——这也正是 §2.4 那 24 个工具存在的理由。

### 5.4 论文里必须交代的边界（学术诚信）

- 固件代码、ROS2 包、诊断脚本的具体实现，是在 AA（AI 助手）深度协作下完成的（逐行讨论 + 代码生成）；
  **Mikl 的贡献集中在**：场景与需求定义、方案选型与拍板、硬件装配与参数实测、
  实验设计与执行、异常现象的首发发现、以及关键独立证据的提供（如查购买记录定轮径、用手机当量尺）。
- 大量"问题定位"由 AA 提出假设，**但每一次结论都由实测数据判定**，
  且项目里有 8 条结论被数据推翻过（见 §4.E），这些推翻过程本身可以写进论文的"迭代"章节。
- 检测算法、温室实测数据**尚未开展**，本文只涉及移动平台与导航部分。
