## 5. 项目经历：新项目放第一个

### 项目名称

```text
基于 STM32F407 + RK3588 + ROS2 的麦轮机器人导航系统
```

### 项目简介

```text
开发了一套从下位机底盘控制到上位机导航的完整麦轮机器人系统。
下位机使用 STM32F407 完成电机PID、编码器、IMU、串口遥测和OTA；
上位机使用 RK3588 + ROS2 Jazzy 完成激光雷达建图、激光里程计和Nav2自主导航；
并开发了Web远程控制与里程计对比工具。
```

### 你负责的工作

```text
1. 设计STM32F407底盘固件
   实现四路编码器电机速度环、麦轮运动学、MPU9250姿态读取、串口遥测协议、OTA升级。
2. 搭建RK3588 ROS2上位机
   实现串口桥、RPLIDAR接入、rf2o激光里程计、slam_toolbox建图、Nav2导航。
3. 开发Web远程控制与可视化
   通过网页实时显示轮式/激光里程计轨迹，支持远程发送底盘串口命令。
4. 排查并解决大量真实问题
   - 雷达坐标系方向反180°
   - 轮式/激光里程计方向不一致
   - Nav2 Jazzy生命周期节点不自动激活
   - map_server不主动发布地图
   - 磁力计航向被固定
   - 陀螺仪Yaw漂移
   - ROS2 QoS不兼容导致图像黑屏
```

## 8. 简历投递注意事项

1. 新项目写最前，老项目放后面。
2. 不要写“精通”，写“熟悉/掌握”。
3. 每个项目写“你做了什么 + 解决了什么问题”。
4. 尽量加 GitHub 仓库链接或视频链接。
5. 不要写“项目很完整/很稳定”，写“完成并调通主要功能，正在持续优化”。
